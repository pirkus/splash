Repository Simulation Guide

Smoothed Particle Hydrodynamics, rendered in real time

This project simulates 2D water with a particle system that approximates the incompressible Navier-Stokes equations. Each particle carries mass, density, pressure, velocity, and force. Neighbor interactions are limited by a smoothing radius to stay performant.

Simulation loop

Each frame rebuilds the spatial hash, computes density and pressure, applies pressure, viscosity, gravity, and boundary forces, then advances the system with velocity Verlet (default) or Euler (optional).

  • 1Build spatial hash grid (cell size = 2h).
  • 2Compute density and pressure for each particle.
  • 3Accumulate pressure, viscosity, gravity, and boundary forces.
  • 4Pick adaptive dt with CFL and integrate.
for each frame:
  build_spatial_hash()
  compute_densities()
  compute_pressures()
  compute_forces()
  integrate(dt)

Core math model

The simulation follows weakly compressible SPH. Density is sampled from neighbors with a smoothing kernel, pressure is derived from an equation of state, and forces are accumulated symmetrically to conserve momentum.

SPH discretization

\[ \rho_i = \sum_j m_j W(r_{ij}, h) \] \[ p_i = k \left(\left(\frac{\rho_i}{\rho_0}\right)^{\gamma} - 1\right) \] \[ a_i^{\text{pressure}} = -\sum_j m_j \left(\frac{p_i}{\rho_i^2} + \frac{p_j}{\rho_j^2}\right) \nabla W(r_{ij}, h) \] \[ a_i^{\text{visc}} = \mu \sum_j \frac{m_j}{\rho_j} (v_j - v_i) \nabla^2 W(r_{ij}, h) \]

Stability controls

\[ c_s = \sqrt{\gamma k / \rho_0} \] \[ \Delta t_{\mathrm{cfl}} = \frac{cfl \, h}{v_{\max} + c_s} \] \[ \Delta t_{\mathrm{force}} = \sqrt{\frac{h}{a_{\max}}} \] \[ \Delta t = \min(\Delta t_{\mathrm{cfl}}, \Delta t_{\mathrm{force}}) \]

These constraints keep particles from moving too far in one step and limit acceleration spikes. Larger k increases c_s and reduces dt.

Method details

Spatial hashing

Particles are hashed into a uniform grid so each particle only checks its 3x3 neighboring cells, keeping neighbor search near O(N).

\[ s = 2h,\quad cell = \left(\left\lfloor \frac{x}{s} \right\rfloor,\; \left\lfloor \frac{y}{s} \right\rfloor\right) \] \[ \text{accept } j \text{ if } \lVert r_{ij} \rVert \lt r_{\text{search}} \]

Boundary penalty

Penalty forces push particles back inside the domain with a damping factor to remove energy near walls. Positions are clamped for safety.

\[ x \lt m:\quad F_x \mathrel{+}= k_b (m - x),\quad v_x \leftarrow v_x d \] \[ x \gt W - m:\quad F_x \mathrel{-}= k_b (x - (W - m)),\quad v_x \leftarrow v_x d \]

Velocity Verlet

Verlet uses two force evaluations per step. It is more stable than Euler at the same dt without a big accuracy cost.

\[ v^{n+1/2} = v^n + \tfrac{1}{2} a^n \Delta t \] \[ x^{n+1} = x^n + v^{n+1/2} \Delta t \] \[ v^{n+1} = v^{n+1/2} + \tfrac{1}{2} a^{n+1} \Delta t \]

Kernels and density estimation

A cubic spline kernel spreads particle mass over a radius of 2h, producing smooth density estimates. Pressure uses a spiky kernel gradient with support limited to h for stable repulsion.

Pressure

Pressure is derived from density using a Tait-style equation of state. The symmetric formulation enforces equal and opposite forces.

Pressure force: src/sph/forces.rs

Viscosity

Viscosity smooths velocity differences across neighbors with a Laplacian kernel, dissipating energy and calming noise.

Boundaries

Penalty forces push particles back inside the domain, with light damping near walls. Positions are clamped for safety.

Integration choices

Velocity Verlet is the default integrator. It uses two force evaluations per step, improving stability without the full cost of higher-order schemes. Semi-implicit Euler is available for faster, rougher motion. 

cargo run --release -- --integrator=verlet
cargo run --release -- --integrator=euler

Verlet keeps trajectories smoother at the same dt.

Performance profile

Spatial hashing keeps neighbor search near O(N). The default settings target real-time performance on typical hardware, with fewer particles but larger smoothing length for a stable pool and visible droplets.
